How upsolving works: a problem becomes due at the 3-, then 7-, then 30-day mark. Hit ✓ Solved if you cleared it yourself — the clock keeps running so it rolls to the next checkpoint. Hit ✗ Missed if you couldn't — the clock resets to today and it starts over. 3 upsolves in a row → Mastered. A single ✗ Missed breaks the streak: the success count drops back to 0, the clock resets, and the 3·7·30 progression starts over.   3 misses total → Focus more.   One upsolve per problem per day.
